Hey! I’m **LimberDev**, a 16-year-old developer from Puerto Rico. This project is my modified, unofficial fork of **VIctory-NVIDIA**, originally created by **trustno1-coder**. I’m building on their work while experimenting with my own changes and learning more about development, performance, and compatibility.

## ⚙️ Performance

With my current modifications, I’m getting around **10–15 FPS** on my PC. I tested it on this setup:

- **GPU:** NVIDIA GeForce RTX 4060 Ti
- **CPU:** 14th-generation Intel Core i5
- **Memory:** 16 GB RAM

These numbers are from my own testing. Performance can vary depending on the specific hardware, game area, drivers, and settings.
